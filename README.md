## 内容

- 100个场景，10个主题，每组12轮，共1,200条双语发言。
- 英文正文28,420词，每组257—303词。
- 100个独立MP3，合计约3.98小时，每组约2—3分钟。
- 美式英语合成语音，仅朗读英文；不同声音区分A/B/C角色。
- 100份英文字幕（SRT）、100份英文稿及可编辑Word、104页PDF、Markdown。
- 保留首版短对话材料，位于`original/`。

## 目录结构

```text
audio/             100个MP3和对应SRT字幕
english_scripts/   100份英文对话稿
data/              完整双语数据、音频清单、核验结果
original/          首版短对话及源数据
*.docx / *.pdf     长对话Word与PDF
*.md               完整双语稿与使用说明
音频索引.csv        编号、主题、词数、音频时长
全部100场景.m3u8    连续播放列表
checksums.sha256   仓库材料的SHA-256校验值
```

案例、系统数据与时间安排均为模拟。使用时请替换为实际工作内容，故障等级、审批和恢复要求以所在组织规则为准。语音为合成声音。
